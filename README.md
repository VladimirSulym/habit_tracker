# Трекер привычек

## Описание проекта

Трекер привычек - это веб-приложение, разработанное на Django, которое помогает пользователям формировать полезные привычки. Приложение позволяет создавать, отслеживать и управлять привычками, а также получать уведомления о запланированных привычках через Telegram.

### Основные возможности

- Создание и управление привычками
- Настройка периодичности выполнения привычек (от 1 до 7 дней)
- Связывание привычек между собой
- Добавление вознаграждений за выполнение привычек
- Публичные и приватные привычки
- Уведомления о привычках через Telegram

## Технологический стек

- **Язык программирования**: Python 3.12
- **Фреймворк**: Django 5.2, Django REST Framework
- **База данных**: PostgreSQL
- **Кеширование и брокер сообщений**: Redis
- **Асинхронные задачи**: Celery, Celery Beat
- **Контейнеризация**: Docker, Docker Compose
- **CI/CD**: GitHub Actions
- **Веб-сервер**: Nginx
- **Уведомления**: Telegram Bot API

## Локальная установка и запуск

### Предварительные требования

- Docker и Docker Compose
- Git

### Шаги по установке

1. Клонировать репозиторий:
   ```bash
   git clone <URL репозитория>
   cd habit_tracker
   ```

2. Создать файл `.env` в корне проекта со следующими переменными:
   ```
   DATABASE_NAME=habit_tracker
   DATABASE_USER=postgres
   DATABASE_PASSWORD=postgres
   DATABASE_HOST=db
   DATABASE_PORT=5432
   SECRET_KEY=<ваш_секретный_ключ>
   DEBUG=True
   BOT_TELEGRAM_TOKEN=<токен_вашего_телеграм_бота>
   ```

3. Запустить проект с помощью Docker Compose:
   ```bash
   docker compose up -d
   ```

4. Приложение будет доступно по адресу: http://localhost:80

### Создание суперпользователя

Для доступа к административной панели Django необходимо создать суперпользователя:

```bash
docker compose exec web python manage.py createsuperuser
```

## Настройка CI/CD

### Настройка GitHub Actions

1. Перейдите в раздел "Settings" вашего репозитория на GitHub
2. Выберите "Secrets and variables" -> "Actions"
3. Добавьте следующие секреты:

   - `DATABASE_NAME` - имя базы данных
   - `DATABASE_USER` - имя пользователя базы данных
   - `DATABASE_PASSWORD` - пароль пользователя базы данных
   - `SECRET_KEY` - секретный ключ Django
   - `DEBUG` - режим отладки (True/False)
   - `DOCKER_HUB_USERNAME` - имя пользователя Docker Hub
   - `DOCKER_HUB_ACCESS_TOKEN` - токен доступа Docker Hub
   - `SERVER_HOST` - IP-адрес сервера
   - `SERVER_USERNAME` - имя пользователя на сервере
   - `SSH_PRIVATE_KEY` - приватный SSH-ключ для доступа к серверу

### Процесс CI/CD

Процесс CI/CD настроен в файле `.github/workflows/main.yml` и включает следующие этапы:

1. **Lint**: Проверка кода с помощью Flake8
2. **Test**: Запуск тестов Django
3. **Build**: Сборка Docker-образов и их публикация в Docker Hub
4. **Deploy**: Деплой на сервер с использованием SSH

## Деплой на сервер

### Предварительные требования

- Сервер с установленными Docker и Docker Compose
- Настроенный SSH-доступ к серверу

### Ручной деплой

1. Подключитесь к серверу по SSH:
   ```bash
   ssh username@server_ip
   ```

2. Создайте директорию для проекта:
   ```bash
   mkdir -p ~/django/habit_tracker
   cd ~/django/habit_tracker
   ```

3. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/VladimirSulym/habit_tracker
   ```

4. Создайте файл `.env` с необходимыми переменными окружения (см. раздел "Локальная установка")

5. Запустите проект:
   ```bash
   docker compose up -d --build
   ```

### Автоматический деплой через GitHub Actions

При настроенном CI/CD процессе, деплой будет происходить автоматически при пуше в репозиторий. Процесс включает:

1. Сборку и публикацию Docker-образов
2. Подключение к серверу по SSH
3. Обновление кода из репозитория
4. Загрузку новых Docker-образов
5. Перезапуск контейнеров

## Структура проекта

- `config/` - настройки проекта Django
- `habits/` - приложение для управления привычками
- `users/` - приложение для управления пользователями
- `.github/workflows/` - конфигурация GitHub Actions
- `docker-compose.yml` - конфигурация Docker Compose
- `Dockerfile` - инструкции для сборки Docker-образа
- `nginx.conf` - конфигурация Nginx

## Дополнительная информация

### Настройка Telegram-бота

1. Создайте бота в Telegram через @BotFather
2. Получите токен бота и добавьте его в переменную окружения `BOT_TELEGRAM_TOKEN`
3. Для получения уведомлений пользователи должны добавить свой Telegram chat ID в профиле

### Мониторинг и логи

Для просмотра логов контейнеров используйте:
```bash
docker compose logs -f [имя_сервиса]
```

Где [имя_сервиса] может быть: web, db, redis, celery, celery-beat, nginx
